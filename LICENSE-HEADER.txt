SPDX Identifier Notes
----------------------------------------------------------------------

Until AMPL is accepted into the SPDX License List, projects should use the
temporary SPDX identifier format:

    SPDX-License-Identifier: LicenseRef-AMPL-1.0

After AMPL is officially accepted into the SPDX License List, projects should
replace the above identifier with the official SPDX identifier assigned by SPDX.

If SPDX assigns the identifier "AMPL-1.0", the correct header becomes:

    SPDX-License-Identifier: AMPL-1.0

Note: The exact identifier string must match the SPDX License List entry exactly.
Do not guess. Use the official SPDX-assigned identifier.
