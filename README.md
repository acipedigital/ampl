# AMPL — A Minimal Permissive License for Modern Software

AMPL (Acipe Minimal Permissive License) is a permissive software license designed
for developers who want maximum freedom of use, preserved recognition of
original authorship upon redistribution, and voluntary collaboration—without
copyleft, coercion, or compliance overhead.

AMPL is platform-neutral and suitable for modern, commercial, embedded, and
cross-platform projects.

**Version:** AMPL-1.0  
**First published:** 2026-02-05

---

## What AMPL Allows

- Use for any purpose, including commercial and closed-source
- Modification and redistribution without source disclosure
- Combination with proprietary or open-source software
- Voluntary contribution back
- Separate licensing or sale of your own contributions
- Explicit permission for archival and preservation use

---

## What AMPL Does Not Require

- No copyleft or share-alike requirements
- No source code disclosure
- No license inheritance
- No network-use or SaaS clauses
- No termination traps
- No patent complexity

AMPL is designed to be legally boring and practically useful.

---

## Attribution, Simply

AMPL requires attribution upon redistribution, nothing more.

If you redistribute:

- Source code → keep existing author attribution notices intact
- Binaries only → include attribution in documentation, credits, or a NOTICE file

Attribution recognizes origin only and does not imply endorsement.

---

## Contribution Is Optional

AMPL treats contribution as a right, not a duty.

You may submit improvements upstream if you wish.
You may also keep changes private or license them separately, including for
compensation.

Choosing not to contribute back has no effect on your rights.

---

## Inspiration

AMPL is informed by early personal computing and demo-scene software cultures,
including those associated with the Amiga era. These references are historical
and cultural only and do not restrict the license’s scope or applicability.
