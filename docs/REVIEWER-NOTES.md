# Reviewer Notes: AMPL-1.0

This document provides clarification for license reviewers, tooling authors,
and standards bodies evaluating the Acipe Minimal Permissive License (AMPL-1.0).

---

## License Category

AMPL-1.0 is a permissive, non-copyleft software license.

It does not require:

- source code disclosure
- license inheritance
- contribution back
- network-use disclosure
- patent grants or retaliation clauses

---

## Core Characteristics

AMPL-1.0 provides:

- an irrevocable grant of rights
- unconditional permission for commercial and closed-source use
- minimal attribution requirements upon redistribution
- explicit permission for archival and preservation use
- explicit recognition of voluntary contribution

---

## Attribution

Attribution is required only upon redistribution.

If source code is redistributed, existing author attributions within the source
must remain intact. If only binaries are redistributed, attribution must be made
available through documentation or equivalent materials.

Attribution serves only to recognize origin and does not imply endorsement.

---

## Contribution Model

Contribution under AMPL-1.0 is entirely voluntary.

Submitting contributions grants permission only for the submitted material and
does not affect the licensing of any non-submitted work. Contributors retain the
right to license or sell their work separately.

---

## Platform Neutrality

AMPL-1.0 places no restrictions on:

- hardware
- operating systems
- emulators or reimplementations
- future platforms

The license name reflects stewardship origin, not technical scope.

---

## Compatibility Statement

AMPL-1.0 is non-viral and does not impose downstream licensing requirements.

It may be used alongside proprietary software and permissive open-source licenses.
Copyleft licenses may impose additional requirements on combined works independently
of AMPL-1.0.

---

## Stability

AMPL-1.0 is intended to be stable and permanent.

Future versions, if published, will be opt-in and will not apply retroactively.
