\# License Comparison (AMPL vs MIT vs GPL)



This table provides a high-level comparison of common concerns.

It is descriptive, not prescriptive.



| Feature / Concern                     | AMPL-1.0 (Acipe)              | MIT License               | GPL (v2/v3)                |

|--------------------------------------|-------------------------------|---------------------------|----------------------------|

| Permissive                           | Yes                           | Yes                       | No                         |

| Copyleft / Share-alike               | No                            | No                        | Yes                        |

| Source disclosure required           | No                            | No                        | Yes                        |

| Closed-source redistribution allowed | Yes                           | Yes                       | No                         |

| Commercial use allowed               | Yes                           | Yes                       | Yes                        |

| Attribution required on redistribution | Yes (explicit)              | Yes (implicit)            | Yes                        |

| Attribution survives closed use      | Yes (explicit)                | Implicit                  | Yes                        |

| License inheritance required         | No                            | No                        | Yes                        |

| Voluntary contribution encouraged    | Yes (explicit)                | Unspecified               | Mandatory (via copyleft)   |

| Preservation explicitly permitted    | Yes                           | Unspecified               | Unspecified                |

| Platform restrictions                | None                          | None                      | None                       |

| Network-use clauses                  | No                            | No                        | AGPL only                  |

| Termination clauses                  | No                            | No                        | Yes                        |

| Patent provisions                    | No                            | No                        | v3 only                    |



AMPL occupies a permissive position similar to MIT, while making attribution,

voluntary contribution, and preservation expectations explicit in the license text.
